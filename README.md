## Run Locally

No package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/purnendu2318/Purnendu_portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Purnendu_portfolio
   ```

3. Open `portfolio/index.html` in your browser.

   Alternatively, open the repository folder in VS Code and use the Live Server extension to preview the page.
